# cookiekiller® portfolio — React version

Портированный на React (Vite) вариант исходного одностраничника Михаила Барашкова.
Вся визуальная логика сохранена: пиксельный loader, частицы-сердце на канвасе,
кастомный курсор-прицел, "магнитные" кнопки, скролл-скью, marquee, стековая
колода карточек Capabilities, hover-превью проектов с pixel-dissolve маской,
меню на весь экран и модалка с формой заявки (mailto).

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

Продакшн-сборка:

```bash
npm run build
npm run preview
```

## Структура

```
index.html          — точка входа Vite (шрифты Google Fonts)
src/main.jsx         — монтирование React-приложения
src/App.jsx           — весь сайт одним компонентом (Loader, Header, Menu,
                          Hero + canvas-частицы, Marquee, Work, About,
                          Capabilities-deck, Experience, Special rates,
                          Footer, модалка формы)
src/i18n.js           — словарь переводов (ru/ro/en) + автоопределение языка
src/index.css         — все стили из оригинала (CSS-переменные, media queries)
```

## Языки (RU / RO / EN)

Переключатель — в шапке сайта. Логика в `src/i18n.js`:

- `detectLang()` при первом заходе смотрит `localStorage`, затем язык
  браузера (`navigator.language`), иначе — русский по умолчанию.
- Выбор языка сохраняется в `localStorage` (`cc_lang`) и переживает перезагрузку.
- `translations.{ru,ro,en}` — весь текстовый контент сайта. Названия проектов
  и теги технологий локализуются через `PROJECTS_I18N` / `projectName()` /
  `projectTags()`; названия брендов (Behance, LinkedIn, названия компаний
  и проектов вроде Victoriabank) намеренно не переводятся.
- `<html lang>`, `<title>` и meta-description обновляются при смене языка.
- Hero-заголовок переигрывает анимацию "выезжания" букв при смене языка
  (сброс `heroIn` в момент клика, чтобы новые буквы монтировались без рывка,
  затем повторный показ через `heroMounted`-эффект).

## Кастомный курсор (только десктоп)

Заменён обычный кружок на прицел из четырёх уголков + точка в центре —
в теме "I KILL BAD UX" (наведение на цель). На интерактивных элементах
прицел увеличивается и разворачивается на 45°. Цвет всегда чистый белый:
при `mix-blend-mode: exclusion` белый гарантированно инвертирует любой фон,
поэтому курсор одинаково хорошо виден и на светлых, и на тёмных секциях
(оригинальный тёмный кружок почти терялся на тёмных секциях). На тач-устройствах
курсор скрыт через `@media(hover:none),(pointer:coarse)`.

## Форма заявки

`mailto:`-отправка сохранена (сайт статический, без бэкенда). После сабмита
модалка на ~3.4с показывает экран "Спасибо, что написали!" с иконкой
галочки, затем закрывается и сбрасывает поля.

## Мобильная адаптация

Скролл-эффект `skewY()` на всём контенте и наклон логотипа теперь считаются
от **сырой** scroll-velocity только на устройствах с точным указателем
(`(hover:hover) and (pointer:fine)`). На тач-устройствах моментум-скролл даёт
рваные значения velocity между кадрами — это и вызывало "шатание" контента
при скролле на телефоне. На десктопе оба эффекта работают как раньше.

## Что изменилось по сравнению с исходным HTML/JS

- Императивный `document.getElementById`-код переписан на React hooks:
  `useState`/`useEffect`/`useRef`, включая единый "master" `requestAnimationFrame`
  цикл (курсор, превью, скью, marquee-скорость, прогресс-бар, лого, частицы).
- Список проектов (`PROJECTS`) и пункты меню (`menuLinks`) вынесены в
  массивы данных и рендерятся через `.map()` вместо ручной генерации DOM.
  Marquee тоже рендерится декларативно (3 копии в JSX для бесшовной прокрутки) —
  раньше контент утраивался через прямую мутацию `innerHTML` в обход React,
  из-за чего при смене языка обновлялась только первая из трёх копий.
- Пиксельное сердце — переиспользуемый компонент `<PixelHeart />`.
- Плавающий preview-блок для наведения на проект и его pixel-dissolve маска
  управляются React state (`hoveredWork`, `previewShow`) вместо прямых
  манипуляций классами.
- Логика формы (mailto-ссылка, статус отправки) переведена на controlled-поведение
  через `ref` + `useState`.
- Иконки (стрелки, соцсети, лапа/череп для спецблока и т.д.) — `@phosphor-icons/react`
  вместо текстовых стрелок/эмодзи, чтобы не дублировать их с переводами.
- Файл `project-logofolio.html` (кейс "Logos for Business") — внешняя страница,
  на неё просто стоит обычная ссылка `<a href="/project-logofolio.html">`;
  при необходимости добавьте роутинг (react-router) или сам файл в `public/`.

## Ассеты

Ссылки на `assets/logofolio/...` ожидают, что файлы будут положены в папку
`public/assets/logofolio/` (Vite отдаёт `public/` как корень статики). В этой
сборке файлов нет — превью для этого проекта покажет плейсхолдер с инициалами,
пока изображения не будут добавлены.
