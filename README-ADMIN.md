# Проекты + Админка — установка

Сайт теперь берёт список проектов из Supabase (бесплатная база данных +
логин + хранилище файлов). Ниже — разовая настройка, минут 10.

## 1. Создать проект в Supabase

1. Зайти на **supabase.com** → **New project** (бесплатный план хватает с запасом).
2. Дождаться, пока проект поднимется (1–2 минуты).
3. Слева **Project Settings → API** — скопировать:
   - `Project URL` → это `VITE_SUPABASE_URL`
   - `anon public` key → это `VITE_SUPABASE_ANON_KEY`

## 2. Накатить схему базы данных

1. Слева **SQL Editor → New query**.
2. Открыть файл `supabase/schema.sql` из этого проекта, скопировать всё содержимое,
   вставить в редактор и нажать **Run**.
3. Это создаст таблицу `projects`, права доступа (публично видно только
   опубликованные проекты, редактировать может только залогиненный админ) и
   бакет `project-media` для фото/видео/гифок.

## 3. Создать себе логин админа

1. Слева **Authentication → Users → Add user → Create new user**.
2. Указать свой email и пароль (это и есть логин/пароль в `/admin`).
3. **Email confirm** можно сразу поставить "Auto Confirm" — чтобы не проверять почту.

## 4. Подключить ключи к проекту

**Локально (для разработки):**
```
cp .env.example .env
```
Вписать в `.env` два значения из шага 1, затем:
```
npm install
npm run dev
```

**На Vercel (для продакшена):**
1. Project → **Settings → Environment Variables**.
2. Добавить `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` с теми же значениями.
3. Redeploy.

## 5. Наполнить проекты

Открыть `/admin` на сайте → войти email/паролем из шага 3.

- **«Новый проект»** — создаёт черновик, дальше открывается редактор.
- **Основное** — адрес страницы (slug), цвет, статус (case / live / dev),
  внешняя ссылка (например на Behance), и *самое важное* — **шаблон**:
  - **Шаблон 1 (кейс)** — вертикальная лента как в присланном тобой HTML:
    заголовок, подзаголовок, строка метаданных (Client / Role / Year …),
    крупные карточки медиа с подписями, список всех блоков внизу.
  - **Шаблон 2 (лента)** — горизонтальная лента фото/видео впритык друг
    к другу на весь экран, скролл колесом мыши или перетаскиванием,
    ховер-зум, точки-навигация, полноэкранный просмотр по клику.
- **Превью на главной** — квадратная миниатюра в списке и большая картинка,
  которая всплывает при наведении на строку.
- **Название и теги** — на 3 языках (en/ru/ro), переключаются вкладками —
  именно они видны на главной странице.
- **Медиа** — перетаскивай файлы (или нажми на зону) — грузится в Supabase
  Storage, поддерживаются картинки, гифки и видео. Порядок блоков меняется
  перетаскиванием за иконку слева. У каждого блока можно задать название
  и подпись-тег (используются в шаблоне 1 как заголовок/тег карточки,
  в шаблоне 2 — как подпись поверх кадра).
- Проект не появится на сайте, пока не включишь **«Опубликован на сайте»**
  и не нажмёшь **«Сохранить»**.
- Порядок проектов в общем списке (`/admin`) = порядок на главной странице —
  просто перетаскивай строки.

## 6. Задеплоить

Обычный флоу: `git push` → Vercel подхватывает и собирает автоматически
(если репозиторий уже подключён к Vercel). Не забудь, что переменные
окружения (шаг 4) должны быть добавлены в Vercel *до* первого деплоя с
админкой — иначе `/admin` покажет экран "Supabase is not configured yet".

## Важно про безопасность

- Пароль от `/admin` — это пароль от твоего Supabase-аккаунта пользователя
  (шаг 3), никак не связан с паролем от самого Supabase-дашборда.
- Можно создать несколько пользователей в Authentication → Users, если
  над сайтом будет работать больше одного человека.
- Публичный (`anon`) ключ Supabase — не секрет, его можно спокойно класть
  во фронтенд-код и переменные Vercel: доступ на запись защищён строками
  безопасности (RLS) в `schema.sql`, а не самим ключом.
